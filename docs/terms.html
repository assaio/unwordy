Unwordy is open-source software and writing guidance maintained in the assaio/unwordy repository. The MIT license below governs use, copying, modification and distribution of its software and documentation.

Using unwordy

Writing and rewriting use the host agent and model you choose. Review generated messages for factual accuracy, technical details and test evidence before using them. Your host and model provider apply their own terms and data policies.

See Privacy and stored data for profile and checker behavior. Questions and support requests can be submitted through GitHub Issues.
